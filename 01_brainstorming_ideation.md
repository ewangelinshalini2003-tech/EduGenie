# Phase 1 — Brainstorming and Ideation

## Project
**EduGenie: a student learning assistant**

## Problem
Students often need a quick way to understand unfamiliar topics, clarify questions, revise class material, practice recall, and organize what to study next. Switching between separate tools can make these small study tasks harder to start.

## Idea
Build one lightweight web application that brings five study activities together: explain a topic at a selected level, answer a question with a revision tip, summarize pasted study material, generate a five-question multiple-choice quiz, and create a four-week learning path.

## Intended users
Students who want structured study support, especially learners who benefit from plain-language explanations and short, actionable practice.

## Value proposition
EduGenie gives students a single place to move from understanding to practice and planning. It can show fallback demo responses without an API key and use Gemini for live responses when configured.

## Initial scope
The current prototype is a local Python HTTP server with a browser interface and separate Python modules for the five learning features. Accounts, saved history, teacher dashboards, and analytics are outside the initial scope.

## Ideation outcome
Proceed with a small, demonstrable prototype. Prioritize a clear homepage, simple inputs, understandable results, and useful behavior in demo mode.
